使用步骤：
如果你没有安装python 先去安装！安装完成请看下面步骤

打开CMD 管理员身份运行 粘贴该指令 pip install openai playwright 回车 

接下来再安装 粘贴playwright install chromium 回车

安装完成后关闭

右键选择64-bit

<img width="557" height="188" alt="image" src="https://github.com/user-attachments/assets/e410870f-f500-4b05-8d69-adcc303d3b60" />

点击Run 看图点击就直接运行了

<img width="429" height="167" alt="image" src="https://github.com/user-attachments/assets/b7ad5cd3-6dea-42df-9f32-7c276a4cedc7" />

如果还是缺少依赖包，请在cmd去安装这个 pip install best-price-mcp

运行之后脚本会弹出 Chromium 浏览器并打开 Steam 聊天页。手动扫码/账号密码登录一次，登录态会保存在 ./steam_browser_profile 目录里，之后再次运行就免登录了。


接下来选中您的群聊打开聊天框，AI大肥鱼就可以开始接管使用，浏览器最好不要关闭，直接点缩放即可

<img width="1282" height="927" alt="image" src="https://github.com/user-attachments/assets/41807ea3-661c-49cd-a41a-f4baddbf1527" />


建议选择好您群聊的文字子频道，以防在主频道 被大肥鱼信息大量轰炸 （人话 嫌吵）
